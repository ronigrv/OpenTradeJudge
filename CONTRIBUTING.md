# Contributing

Open an issue describing the behavior or metric you want to improve. Keep pull
requests focused and include a reproducer or synthetic example where relevant.
Run `python -m unittest discover -v` before proposing changes.

Use only synthetic or explicitly redistributable inputs. Do not contribute
credentials, account identifiers, real trade records, proprietary strategies,
or code copied from a private project. Review example labels independently of
model outputs. State clearly whether reported results are fixtures or live runs.

The initial project was developed with AI coding assistance. The maintainer is
responsible for reviewing changes. There is no automated merge or release policy.
